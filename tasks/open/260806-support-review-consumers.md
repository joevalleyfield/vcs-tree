# Support Recurring Review Consumers

Turn the 2026-08-06 playbook trial into factual, supported affordances that let
an external reviewer spend attention on domain judgment rather than ledger
mechanics.

## Current Reality

Snapshot v2, temporal facts, mechanical predicates, deltas, and pulse are
implemented. A real 68-repository trial found useful initial-boundary premises,
but required private-ledger parsing and exposed false movement, repeated
low-level events, opaque query identity, a silent cold rebuild, and an awkward
current-target/parent query.

## Desired Reality

The external playbook can capture once, obtain trustworthy grouped movement,
and request current candidate facts with paths, clocks, completeness, and
bounded working-copy evidence. `vcs-tree` remains factual and retains no
review conclusion or disposition.

## Gap Analysis

- Comparison recovery and identical divergent sets can appear as movement.
- Movement summaries repeat low-level labels without grouping descriptions.
- Query consumers must join opaque repository keys to private ledger mappings.
- Current workspace target and exact parent facts are not conveniently
  projected together.
- Explicit retained queries rebuild historical temporal state silently.
- Truncated working-copy evidence lacks a playbook-friendly supported follow-up.

## Known Facts / Assumptions / Unknowns

- Fact: generation 12-to-13 provides concrete regression evidence.
- Fact: initial-boundary pressure and content classification remain consumer
  conclusions.
- Assumption: a factual projection can remove relational mechanics without
  adding semantic policy.
- Unknown: whether the smallest candidate surface is a query extension, a
  batch projection, or another replaceable service boundary.

## Investigations

- Preserve the exact real-corpus pair and reduce each sticky case to fixtures.
- Exercise public surfaces only; private `snapshots.json` parsing is evidence
  of a gap, not the desired consumer contract.
- Measure cold/warm index and packet costs on the retained corpus.
